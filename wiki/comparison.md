# 기존 봇과 단일 에이전트 비교

2026년 11월 20일, 동일 모델 `gpt-6.2-sol`에 같은 학생 질문을 입력했다. 7개 시나리오 중 하나는 두 턴 대화여서 버전별 답변은 8개다. 사전에 정한 문항별 요구를 모두 충족한 답변은 **기존 봇 4/8, 단일 에이전트 8/8**이었다. 차이가 난 네 답변은 학교가 공개한 해설이나 배점이 필요한 질문이었다.

## 소요 시간과 API 사용량

| 지표 | 기존 봇 | 단일 에이전트 |
| --- | ---: | ---: |
| 답변당 시간 중앙값 | 4.8초 | 10.1초 |
| 모델 호출 수 합계 | 8 | 24 |
| 입력 토큰 합계 | 12,937 | 139,308 |
| 출력 토큰 합계 | 1,242 | 2,189 |

시간은 첫 모델 요청 직전부터 해당 턴의 답변을 얻기까지로, Discord 전송은 제외했다. 입력 토큰은 API가 각 호출에서 보고한 양을 합산했다. 이전 대화와 PDF 이미지가 후속 호출의 입력에 포함될 수 있으며, 이 합계에서 실제 청구액을 산출하지 않았다. 예를 들어 일반 1-2의 감점 질문에서 에이전트는 문제·채점표·예시 답안 세 쪽을 열었다. 감점만 물을 때는 채점표 한 쪽으로도 답할 수 있다.

## 재현 범위

기존 버전은 원래 시스템 프롬프트, 사진 입력, 직전 응답 연결 방식을 사용했다. 단일 에이전트에는 같은 프롬프트에 자료 활용 지침과 검색·PDF 열람 도구를 더했다. 두 버전 모두 출력 한도 4,000토큰을 사용했다. 각 시나리오는 새 대화로 시작했고, 후속 질문은 같은 버전의 앞 답변에만 연결했다. 사진은 실제 자연 모의 문제지 4쪽이며, 학생 개인정보를 포함하지 않는다.

각 시나리오를 버전별 한 번 실행한 뒤 답변을 원문과 대조하여 판정했다. 일부 문항은 위키 설계 때도 검토한 사례다. 이 점수는 이번 질문의 충족 개수이며 전체 수험생에 대한 정확도나 학습 효과를 측정한 값은 아니다. [질문과 평가 기준](../tools/compare_tutors.py) · [실제 답변·호출 기록](comparison-answers.jsonl)
