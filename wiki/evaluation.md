# 검색과 첨삭의 검증 사례

작업 폴더에서 `.\.venv\Scripts\python.exe tools/wiki.py check`를 실행한다. 원본의 바이트 수와 SHA-256, 출처 대장과 디스크의 파일 목록, 문항 식별자의 중복, 소문항 수, 내부 링크, PDF 인용 쪽수 범위, [검색 질의별 기대 결과](evaluation.json)를 대조한다. 검색 결과가 하나여야 하는 일부 사례에서는 카드에 정정식·채점 문구·해당 쪽 링크가 있는지도 검사한다.

## 실제 답변을 평가할 때

학생에게 아래처럼 물어본 뒤 **출처 선택**, **수학·자료 해석**, **채점표 적용**, **학생이 요청한 도움 수준**을 각각 확인한다. 자동 검사는 자료 선택과 참조의 일부를 재현한다. 아래의 문장 수준 평가는 봇에 검색을 연결한 뒤 생성된 답변에 적용한다.
