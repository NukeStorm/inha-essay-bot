## 검색과 검증

프로젝트 루트에서 실행한다. 별도 패키지나 API 키 없이 표준 Python으로 동작한다.

```powershell
.\.venv\Scripts\python.exe tools/wiki.py find --year 2027 --exam 모의 --track 의예 --question 1-3 --read
.\.venv\Scripts\python.exe tools/wiki.py find --year 2026 --exam 기출 --track 오전 --question 1
.\.venv\Scripts\python.exe tools/wiki.py find 접선
.\.venv\Scripts\python.exe tools/wiki.py check
```

번호만 주면 조건에 맞는 후보를 함께 표시한다. 검색 결과가 여러 개면 학생에게 학년도 또는 시험지를 확인한다. CLI와 디스코드 튜터는 같은 문항 검색 함수를 사용한다. [기존 봇과 단일 에이전트 비교](comparison.md)
